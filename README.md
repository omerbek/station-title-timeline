# Station Title Timeline / HTML zaman çizelgesi

## Türkçe

[Canlı aracı aç](https://omerbek.github.io/station-title-timeline/).

Bir başlığın giriş, bekleme ve çıkış zamanlarını oynat.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.


## Sahne ayarları

- Başlık
- Giriş süresi (s)
- Çıkış süresi (s)

Sekiz saniyelik zaman çizelgesinden bir kare seçip **PNG indir** ile 720 × 405 piksel dışa aktarabilirsin.

## English

Compose a title and adjust its entrance and exit timing.

Open [the live tool](https://omerbek.github.io/station-title-timeline/) or open `index.html` in a browser. Switch between Turkish and English in the page header. Use the timeline to select a frame and **Download PNG** to save it at 720 × 405 pixels.
